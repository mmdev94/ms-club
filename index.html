MS Club · room test

Checks three things before the real game is built: two browsers can sit at one table with no server, only the host can change the table, and scores can be posted to and read from public relays.

How to test: tap Create a table on one device, open the invite link on another (ideally on a different network, e.g. phone on mobile data). Host: tap Deal. Guest: tap Try to change the board. Then post and load a score. Copy the results from both devices.
